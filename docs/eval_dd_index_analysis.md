# eval_dd.py Index Continuity Analysis

## Eval Loop Structure

### Initialization (first chunk, no prefix)
```python
obs, env_state = env.reset_to_level(...)
action_chunk = policy.action(key, obs, ...)  # Full generation, all positions from scratch
```
- **First inference_delay actions**: Generated by the model from scratch (no previous chunk).
- The first chunk has no "prefix from elsewhere" — everything is predicted.

### execute_chunk iterations

Each iteration receives `(rng, obs, env_state, action_chunk, n)`.

**Key variables:**
- `action_chunk`: The current chunk buffer (shifted from previous iteration, or full chunk at iter 0).
- `next_action_chunk = policy.realtime_action(obs, action_chunk, inference_delay, execute_horizon)`

**In `realtime_action`:**
- Prefix = `prev_action_chunk[:, :inference_delay]` (first `inference_delay` positions of the *passed-in* chunk).
- The passed-in `prev_action_chunk` is the current `action_chunk` from the carry.

### Index flow across iterations

**Iteration 0:**
- `action_chunk` = full output from `policy.action(obs_0)` — shape `[B, chunk_size, action_dim]`
- prefix = `action_chunk[:, 0:inference_delay]` = positions [0, 1, ..., d-1]
- `action_chunk_to_execute` = [action_chunk[:, :d], next_action_chunk[:, d:execute_horizon]]
- Execute `execute_horizon` steps.
- `next_action_chunk` (for carry) = [next_action_chunk[:, execute_horizon:], zeros] — left shift by `execute_horizon`.

**Iteration 1:**
- `action_chunk` = shifted chunk from iter 0 = [old_next[:, execute_horizon:], zeros]
- So `action_chunk[i]` = old_next[i + execute_horizon] for i in [0, chunk_size - execute_horizon)
- **prefix = action_chunk[:, :inference_delay] = old_next[:, execute_horizon : execute_horizon + inference_delay]**
- The prefix is positions **[execute_horizon, execute_horizon+1, ..., execute_horizon+inference_delay-1]** of the previous full chunk, NOT [0, 1, ..., inference_delay-1].

**Iteration k (k≥1):**
- prefix = positions [execute_horizon, ..., execute_horizon + inference_delay - 1] of the chunk generated at the previous iteration.
- obs = observation after k * execute_horizon env steps.
- GT chunk we want = actions [k*execute_horizon, k*execute_horizon+1, ..., k*execute_horizon + chunk_size - 1].

## Self-forcing training fix

Current bug: at k≥1 we use `prefix = prev_chunk[:, :inference_delay]` (positions 0..d-1).

Correct: `prefix = prev_chunk[:, execute_horizon : execute_horizon + inference_delay]` (positions h..h+d-1).

Constraint: `execute_horizon + inference_delay <= action_chunk_size`.
